# PMB — Praktek Mandiri Bidan

Aplikasi Android untuk menggantikan buku register kunjungan pasien pada praktek mandiri bidan.

## Kegunaan

- Mencatat kunjungan pasien secara digital.
- Mencari dan merekap riwayat kunjungan.
- Mencetak catatan kunjungan.
- Bekerja tanpa koneksi internet.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Platform | Android |
| Bahasa | Kotlin + Jetpack Compose |
| Data | Basis data lokal di perangkat |
| Sifat | Luring, tanpa server |

## Alur singkat

1. Bidan membuka aplikasi dan membuat catatan kunjungan.
2. Catatan disimpan di perangkat.
3. Kunjungan dapat dicari, direkap, dan dicetak.
4. Tidak ada data pasien yang dikirim ke luar perangkat.
